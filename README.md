# Vertex

A kernel exploit for all devices on iOS 14.0 - 15.7.3. The vulnerability exploited is the same one used in the PhysPuppet exploit in [kfd](https://github.com/felix-pb/kfd) and the IOSurface kernel read/write technique used was originally used in [weightBufs](https://github.com/0x36/weightBufs) and then adapted for kfd in [opa334's fork](https://github.com/opa334/kfd).

This code has been published alongside my blog post on how to write a kernel exploit, which you can find over at https://alfiecg.uk.
